## 一、技术栈一览（MVP 选型）

| 维度 | 选型 | 理由 |
|---|---|---|
| **包管理** | pnpm 10 | monorepo 友好 |
| **Monorepo** | Turborepo 2 | 增量构建 |
| **前端框架** | Next.js 16 (App Router) | SSR + i18n 完善 |
| **UI 库** | React 19 + shadcn/ui + Tailwind v4 | 可复制可定制 |
| **i18n** | next-intl 4 | 双语 Day1 必装 |
| **后端** | NestJS 11 | 模块化 |
| **ORM** | Prisma 5 | 类型安全 |
| **数据库** | PostgreSQL 16 + Redis 7 | 主库 + 缓存 |
| **视频处理** | FFmpeg 6 → HLS | 自适应码率 |
| **上传** | TUS 协议 | 断点续传 |
| **队列** | BullMQ | 转码、解冻 |
| **存储** | S3 / MinIO | 视频、封面 |
| **鉴权** | Better Auth 1.x | 手机号 OTP |
| **CDN** | Cloudflare / 阿里云 | 视频分发 |
| **支付** | Stripe / 微信 / 支付宝 + 越南预留 | 见第 6 节 |
| **测试** | Vitest + Playwright | 单测 + E2E |
| **部署** | Docker Compose | 单机起步 |

**MVP 阶段不做**：K8s、微服务拆分、Service Mesh、Istio 等。

## 二、Monorepo 项目结构（v7.1）

> **观众 / 创作者**：单域名路径分区（`apps/web` :3000）。  
> **管理端**：独立应用 `apps/admin` :3001；生产独立域名 `admin.velvetmovie.space`。管理鉴权为独立 Admin JWT，**不**与观众 Cookie 共享。  
> **禁止**：为观众/创作者再拆多子域导致 Cookie 共享问题。

```
velvet-platform/
├── apps/
│   ├── web/                              # 观众 / 创作者 → :3000
│   └── admin/                            # Ops 管理端 → :3001
├── packages/
│   ├── ui/
│   ├── api-client/
│   ├── validators/
│   └── tsconfig/
├── services/
│   └── api/                              # NestJS → :4000
└── docs/
```

**本地访问**：

| 地址 | 用途 |
|---|---|
| `http://localhost:3000` | 观众 / 创作者 |
| `http://localhost:3001` | 管理端 |
| `http://localhost:4000` | NestJS API（一般经前端同源代理） |

## 四、支付抽象架构（核心）

### 4.1 PaymentProvider 接口

```typescript
// packages/payments/src/interface.ts
export type PaymentRegion = 'VN' | 'CN' | 'GLOBAL';

export interface CreateOrderParams {
  orderNo: string;          // 业务订单号
  amountVnd: number;        // 越南盾（注意：内部统一用 VND，渠道层做汇率转换）
  userId: number;
  description: string;
  returnUrl: string;        // 支付成功跳转
  notifyUrl: string;        // webhook 回调
}

export interface PaymentOrder {
  orderNo: string;
  payUrl?: string;          // 跳转支付的 URL
  qrCode?: string;          // 二维码内容
  deeplink?: string;        // App-to-App
  expiredAt?: Date;
}

export interface PaymentStatus {
  orderNo: string;
  status: 'pending' | 'paid' | 'failed' | 'refunded';
  paidAt?: Date;
  externalRef?: string;
}

export interface WebhookEvent {
  orderNo: string;
  status: 'paid' | 'failed' | 'refunded';
  externalRef: string;
  rawPayload: string;
}

export interface PaymentProvider {
  readonly name: string;
  readonly region: PaymentRegion;
  createOrder(params: CreateOrderParams): Promise<PaymentOrder>;
  queryOrder(orderNo: string): Promise<PaymentStatus>;
  verifyWebhook(payload: string, signature: string, headers: Record<string, string>): WebhookEvent;
  refund?(params: { orderNo: string; amountVnd: number; reason: string }): Promise<{ success: boolean }>;
}
```

### 4.4 区域检测与前端展示

```typescript
// packages/payments/src/region-detector.ts
import type { PaymentRegion } from './interface';

// MVP 简化版：用 Accept-Language + Cloudflare/Vercel 提供的 IP 国家 header
export function detectRegion(req: Request): PaymentRegion {
  const country = req.headers.get('cf-ipcountry')      // Cloudflare
                 || req.headers.get('x-vercel-ip-country')  // Vercel
                 || req.headers.get('x-forwarded-for-country')
                 || 'GLOBAL';

  if (country === 'VN') return 'VN';
  if (country === 'CN') return 'CN';
  return 'GLOBAL';
}

export function getAvailableMethods(region: PaymentRegion, locale: string): string[] {
  if (region === 'VN') {
    // 越南用户：本地支付 + 兜底
    return ['vietqr', 'momo', 'zalopay', 'bank_transfer', 'stripe'];
  }
  if (region === 'CN') {
    return ['wechat', 'alipay', 'stripe', 'bank_transfer'];
  }
  return ['stripe', 'bank_transfer'];
}
```

### 4.6 Webhook 统一入口

```typescript
// services/api/src/modules/webhooks/webhooks.controller.ts
@Controller('api/v1/webhooks')
export class WebhooksController {
  @Post(':method')
  async handle(
    @Param('method') method: string,
    @Req() req: Request,
    @Body() body: any,
    @Headers() headers: Record<string, string>,
  ) {
    const provider = getProvider(method);
    const rawPayload = JSON.stringify(body);

    // 1. 验签（每个 Provider 自己实现）
    const event = provider.verifyWebhook(rawPayload, body.signature || '', headers);

    // 2. 更新订单状态
    const order = await this.prisma.order.findUnique({
      where: { orderNo: event.orderNo },
    });
    if (!order) throw new NotFoundException();

    // 幂等：已 PAID 直接返回，避免重复 webhook 重复入账（见 00 §六）
    if (order.paymentStatus === 'PAID') {
      return { code: 0, message: 'already paid' };
    }

    await this.prisma.order.update({
      where: { id: order.id },
      data: {
        paymentStatus: event.status === 'paid' ? 'PAID' : 'FAILED',
        externalRef: event.externalRef,
        paidAt: event.status === 'paid' ? new Date() : null,
      },
    });

    // 3. 钱包加款（仅 TOPUP 类型）
    if (order.orderType === 'TOPUP' && event.status === 'paid') {
      await this.walletService.credit(order.userId, order.amountVnd, order.orderNo);
    }

    return { code: 0, message: 'ok' };
  }
}
```

> 读写分离、多实例扩到 4 节点 = **增长期**，不是地基期目标。

### 5.2 关键性能策略

| 场景 | 策略 |
|---|---|
| **首页加载 < 1s** | CDN + Redis 缓存首页 |
| **视频起播 < 1s** | HLS 预加载 + CDN + **签名 URL** |
| **详情页 < 800ms** | SSR + Redis 缓存元信息 |
| **API < 200ms** | 索引 + Redis + 连接池 |
| **上线并发目标** | **千级同时在线稳定**（视频连接主要由 CDN 扛）|
| **增长期** | web/api 水平扩容；必要时再上从库 |
### 5.3 片源管理（重点）

```
创作者上传 MP4
    ↓
TUS 断点续传 → S3 temp 桶（鉴权后上传）
    ↓
上传完成 → 后端投递 Bull 队列 job
    ↓
transcoder worker 拉取任务
    ↓
FFmpeg 转码：480p + 720p HLS + 封面
    ↓
切片上传到 S3 production 桶（私有，不公网裸奔）
    ↓
更新 Episode.hlsUrl（存「对象路径」，不是永久公网 URL）
    ↓
观众点播放 → API 校验解锁 → 签发「短时签名 URL」（5–15 分钟）
    ↓
Video.js 用签名 URL 拉 CDN；过期必须重新 /play
```

**关键点**：
- 切片约 6 秒；关键帧间隔约 2 秒；480p + 720p
- **【v7 强制】** 禁止返回永久公开 m3u8；必须用 CloudFront/阿里云 **Signed URL / Signed Cookie**
- token 建议绑定：`userId + episodeId + exp`
- 转码失败：Bull 重试 + 死信队列，创作者后台可见失败原因

### 5.4 数据库稳定性

| 措施 | 说明 |
|---|---|
| **连接池** | Prisma + PgBouncer |
| **索引** | 外键 + 查询/排序字段 |
| **慢查询** | `pg_stat_statements` |
| **备份** | 每日 `pg_dump` → S3，保留 30 天 |
| **主从复制** | **增长期再上**；上线期先单主 + 备份即可 |

### 5.5 监控告警

| 维度 | 工具 | 告警阈值 |
|---|---|---|
| 应用错误 | Sentry | 错误率 > 1% |
| 服务可用性 | UptimeRobot | 5 分钟内失败 |
| API 延迟 | Prometheus | P95 > 1s |
| DB 连接 | pg_stat_activity | 连接数 > 80 |
| 队列堆积 | Bull Board | 等待任务 > 100 |
| CDN 流量 | Cloudflare Analytics | 带宽 > 5 Gbps |

```
1. 用户输入 +84 手机号
2. POST /api/auth/phone-number/send-otp
3. SMS 网关发送 6 位 OTP（5 分钟有效）
4. 用户输入 OTP → POST /api/auth/phone-number/verify
5. 后端创建 user + wallet（首次）
6. 颁发 session cookie（httpOnly + secure + SameSite=Lax）
7. 重定向
```

### 6.2 视频上传与转码

```
1. 创作者选择视频文件
2. 前端 tus-js-client 创建上传任务
   POST /api/v1/upload/create → uploadId + tusEndpoint
3. 分片上传（每片 5MB，断点续传）
   PATCH /api/v1/upload/{id}
4. 上传完成 → POST /api/v1/upload/{id}/complete
5. 后端投递 Bull 队列转码任务
6. transcoder worker 拉取并执行 FFmpeg
7. Web 端通过 SSE 接收进度
   event: "transcode.progress" data: { percent: 75 }
   event: "transcode.done" data: { hlsUrl: "..." }
```

### 6.3 付费解锁与分账

```typescript
// services/api/src/modules/orders/orders.service.ts
async unlockEpisode(userId: number, episodeId: number, paymentMethod: string) {
  return await this.prisma.$transaction(async (tx) => {
    // 1. 校验
    const episode = await tx.episode.findUniqueOrThrow({ where: { id: episodeId } });
    if (await tx.userUnlock.findUnique({
      where: { userId_episodeId: { userId, episodeId } }
    })) throw new ConflictException('Already unlocked');

    const wallet = await tx.wallet.findUniqueOrThrow({ where: { userId } });
    if (wallet.balanceVnd < episode.priceVnd) {
      throw new BadRequestException('Insufficient balance');
    }

    // 2. 扣款
    await tx.wallet.update({
      where: { userId },
      data: { balanceVnd: { decrement: episode.priceVnd } },
    });
    await tx.walletTransaction.create({
      data: {
        walletUserId: userId,
        type: 'UNLOCK',
        amountVnd: -episode.priceVnd,
        balanceAfter: wallet.balanceVnd - episode.priceVnd,
        remark: `Unlock episode ${episodeId}`,
      },
    });

    // 3. 分账（70/30）
    const creator = await tx.creator.findUniqueOrThrow({ where: { id: episode.creatorId } });
    const creatorIncome = Math.floor(episode.priceVnd * creator.revenueShare);
    const platformFee = episode.priceVnd - creatorIncome;

    // 4. 创建订单
    const order = await tx.order.create({
      data: {
        orderNo: generateOrderNo(),
        userId,
        creatorId: episode.creatorId,
        orderType: 'EPISODE_UNLOCK',
        episodeId,
        amountVnd: episode.priceVnd,
        creatorIncomeVnd: creatorIncome,
        platformFeeVnd: platformFee,
        paymentMethod: paymentMethod.toUpperCase(),
        paymentStatus: 'PAID',
        paidAt: new Date(),
      },
    });

    // 5. 创作者 pending 收益
    await tx.creatorEarning.upsert({
      where: { creatorId: episode.creatorId },
      create: { creatorId: episode.creatorId, pendingVnd: creatorIncome, totalEarnedVnd: creatorIncome },
      update: {
        pendingVnd: { increment: creatorIncome },
        totalEarnedVnd: { increment: creatorIncome },
      },
    });

    // 6. 记录解锁
    await tx.userUnlock.create({
      data: { userId, episodeId, orderId: order.id },
    });

    // 7. T+7 解冻
    await this.queue.add('release-earning', {
      creatorId: episode.creatorId, amount: creatorIncome,
    }, { delay: 7 * 24 * 60 * 60 * 1000 });

    return order;
  }, { isolationLevel: 'Serializable', timeout: 10000 });
}
```

### 6.4 T+7 自动解冻

```typescript
// services/api/src/queues/release-earning.processor.ts
@Processor('release-earning')
export class ReleaseEarningProcessor {
  @Process()
  async handle(job: Job) {
    const { creatorId, amount } = job.data;
    await this.prisma.$transaction([
      this.prisma.creatorEarning.update({
        where: { creatorId },
        data: {
          pendingVnd: { decrement: amount },
          availableVnd: { increment: amount },
        },
      }),
    ]);
  }
}
```
