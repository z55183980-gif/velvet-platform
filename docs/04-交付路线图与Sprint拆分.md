## 一、为什么改成 8 周

4 周塞进双语 + 多支付生产 + 转码 + KYC + 分账，必然偷工：**幂等、对账、签名 URL、备份**——这些才是收真钱的地基。

| 阶段 | 周次 | 关键词 |
|---|---|---|
| 地基期 | W1–2 | 骨架、双语、Schema、鉴权、支付抽象、幂等/对账、上传转码、签名播放 |
| 闭环上半 | W3–4 | 浏览播放、登录钱包、1 条自动收款 + 银行兜底、解锁 |
| 闭环下半 | W5–6 | 分账提现、审核、微信支付宝、越南 sandbox |
| 上线期 | W7–8 | 看板 Banner、监控备份、CDN、压测、真交易上线 |

## 二、W1–2 地基期（不准堆花活）

### 目标

工程可跑；写钱路径有幂等测试；片源能签权播放；双语全通。

### 关键任务

| 周 | 任务 |
|---|---|
| W1 | 官方 Turborepo + Next（**唯一** `apps/web`，路径 `/` `/creator` `/admin`，端口 **3000**）+ NestJS（**:4000**）；Docker（PG/Redis/MinIO）；next-intl；Prisma（含 v7 字段）；Better Auth OTP（SMS 可 mock）|
| W1 | PaymentProvider 接口 + webhook 幂等框架 + 对账 Job 空跑；SystemSetting |
| W2 | TUS 上传 + FFmpeg HLS worker；**CloudFront/OSS 签名 URL**；播放页接签名地址 |
| W2 | 钱包扣款单测（并发/重复 webhook 不加款两次）|

### 验收

- [ ] **仅** `localhost:3000` + `localhost:4000` 两个业务端口；`/creator` `/admin` 同域 Cookie 共享
- [ ] vi / zh（越南语 / 中文）切换与路由正常
- [ ] 上传→转码→签名播放跑通
- [ ] 重复 webhook 测试通过
- [ ] 日对账 Job 能写出空报告
