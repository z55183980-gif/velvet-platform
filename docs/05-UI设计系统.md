# 05 · UI 设计系统（DramaVN）

> 本文档是 DramaVN 前端的**视觉与交互唯一真相源**。它直接对齐 02 的技术栈（Next.js 16 App Router + React 19 + shadcn/ui + Tailwind v4），并服务 01 的双语需求（vi 默认 + zh）。
>
> 设计目标：**高端、大气、国际范**。三条不可妥协的底线：
> 1. **呼吸感** —— 间距系统必须被强制执行，"挤"是 Bug，不是风格。
> 2. **可读性** —— 字距（letter-spacing）与行高（line-height）是排版的一等公民，不是事后调整。
> 3. **一致性** —— 一切视觉值来自令牌（token），禁止散落在组件里的魔法数字。

---

## 〇、设计目标与原则

### 0.1 "高端大气国际范"到底指什么
- **电影感（Cinematic）**：以深色为基底，用大面积留白与光影对比制造"贵气"，不走短剧 App 常见的花花绿绿高饱和路线。
- **编辑式排版（Editorial）**：标题用负字距大字号、正文用宽松行高，像高端杂志/流媒体官网（Netflix、Apple TV、Disney+ 的克制版）。
- **克制的高光**：一个自信的品牌强调色 + 一个"高级金"用于会员/尊享，其余皆中性灰阶。
- **国际通用细节**：大写标签加字距、焦点环可见、动效短而稳、双语切换无跳变。

### 0.2 双主题
- **深色优先（默认）**：`theme=dark`，电影感主调，覆盖 90% 场景。
- **浅色备选（可选）**：`theme=light`，用于白天户外/打印/分享截图，令牌对称映射。
- 两套共用同一套间距/字距/圆角/动效令牌，只换颜色令牌。

## 一、设计语言（Design Language）

| 维度 | 决策 |
|---|---|
| 基调 | 深色、冷中性、低饱和背景 + 温暖强调色 |
| 情绪关键词 | 电影感 · 克制 · 信赖 · 尊享 |
| 密度 | 宽松（generous），信息块之间留白优先于堆叠 |
| 形状语言 | 中等圆角（卡片 16–20px），柔和分层阴影 |
| 动效 | 短（150–250ms）、缓出、克制，尊重 `prefers-reduced-motion` |

## 三、字体与排版系统（Typography）— 重点解决"挤"

这是本文档最关键的章节。开发最常翻车的就是这里：**正文行高写 1.2、标题不加字距、盒子里 padding 只有 8px**，结果字全挤成一团。下面给出可执行的规则。

### 3.1 字体族
```
--font-sans（正文/UI）
  "Plus Jakarta Sans",        /* 显示与 UI，带编辑式国际感，原生支持越南语变音 */
  "Inter",                    /* 正文备选 */
  "PingFang SC",              /* 中文（macOS/iOS）*/
  "Noto Sans SC",             /* 中文（跨平台回退）*/
  system-ui, sans-serif

--font-display（大标题/品牌字，可选更紧的字距）
  同 --font-sans，但 weight 更重、tracking 更负
```
> **越南语变音（diacritics）**：Plus Jakarta Sans / Inter 均完整支持越南语声调符号（à á ả ã ạ 等）。**禁止**使用会裁切变音的窄体或行高过紧的字体。

### 3.2 全局字体渲染（必须写进 `globals.css`）
```css
:root {
  text-rendering: optimizeLegibility;
  -webkit-font-smoothing: antialiased;
  -moz-osx-font-smoothing: grayscale;
  font-feature-settings: "kern" 1, "liga" 1, "calt" 1, "cv11" 1;
  /* 越南语：开启连字与字距调整，避免变音符号相互碰撞 */
}
```

### 3.3 字距（letter-spacing）规则表 — 这是"国际范"的细节
| 场景 | letter-spacing | 说明 |
|---|---|---|
| Display / H1（≥40px） | `-0.02em` | 越大越紧，避免松散 |
| H2–H3（24–39px） | `-0.01em` | 轻微收紧 |
| H4–H5（18–23px） | `0` | 默认 |
| 正文 / 列表 | `0` | 绝不手动加负字距 |
| **大写标签 / 导航 / 按钮大写** | `+0.08em ~ +0.12em` | 国际范关键：全大写必须加字距，否则 diacritics 互撞 |
| 小字注释（≤12px） | `+0.01em` | 防糊 |

> **铁律**：任何 `text-transform: uppercase` 的元素，必须同时设置 `letter-spacing ≥ 0.08em`。

### 3.4 行高（line-height）规则 — 解决"被挤在一起"
| 场景 | line-height |
|---|---|
| Display / H1 | `1.05 – 1.1` |
| H2–H3 | `1.15 – 1.25` |
| H4–H5 | `1.3` |
| **正文 / 段落（body）** | **`1.65 – 1.7`（强制）** |
| 列表项 | `1.6` |
| 按钮文字 | `1.2`（单行，不需宽松）|

> **铁律**：`body` 全局 `line-height: 1.65`。任何组件**不得**把正文行高压到 1.4 以下。段落之间用 `margin`（见 §4.3），不要用双倍行高硬撑。

### 3.5 模块化字号阶梯（Type Scale，比率 ≈ 1.25）
| Token | 桌面(px/rem) | Weight | Tracking | Leading | 用途 |
|---|---|---|---|---|---|
| `text-display` | 56 / 3.5 | 700 | -0.02em | 1.05 | 首页 Hero 主标题 |
| `text-h1` | 40 / 2.5 | 700 | -0.02em | 1.1 | 页面主标题 |
| `text-h2` | 32 / 2 | 700 | -0.01em | 1.15 | 区块标题 |
| `text-h3` | 24 / 1.5 | 600 | -0.01em | 1.2 | 卡片标题 |
| `text-h4` | 20 / 1.25 | 600 | 0 | 1.3 | 小标题 |
| `text-body-lg` | 18 / 1.125 | 400 | 0 | 1.7 | 导语/正文大 |
| `text-body` | 16 / 1 | 400 | 0 | **1.65** | 正文默认 |
| `text-body-sm` | 14 / 0.875 | 400 | 0 | 1.6 | 次要正文 |
| `text-caption` | 12 / 0.75 | 500 | +0.01em | 1.5 | 注释/元信息 |
| `text-overline` | 12 / 0.75 | 600 | **+0.1em** | 1.4 | 大写小标（如 "PHIM MỚI"）|

> 移动端 `text-display` 降为 40px、`text-h1` 降为 32px（见 §八）。

## 四、间距系统（Spacing Scale）— 重点解决"挤"

### 4.1 基础单位与尺度表（4px 基准，Tailwind v4 `--spacing`）
```
--spacing: 0.25rem;  /* 4px，Tailwind 默认，沿用 */
```
派生尺度（像素 / 令牌值）：
```
1  = 4px      2  = 8px      3  = 12px     4  = 16px
5  = 20px     6  = 24px     8  = 32px     10 = 40px
12 = 48px     16 = 64px     20 = 80px     24 = 96px
32 = 128px
```
> **禁止**出现 2px/6px/10px 这类"将将够"的间隙——宁大勿小。

### 4.2 语义间距令牌（让"留白"有名字）
```
--space-xs   4px    内联小元素间隙（图标与文字）
--space-sm   8px    紧凑列表项间隙
--space-md   16px   卡片内默认间隙 / 控件间距
--space-lg   24px   区块内分组间距
--space-xl   40px   区块之间
--space-2xl  64px   页面 section 垂直韵律
--space-3xl  96px   首页 Hero 上下留白
```

### 4.3 组件内边距底线（minimum padding，违反即 Bug）
| 组件 | 最小内边距 |
|---|---|
| 按钮（md） | `10px 20px`（高 ≥ 44px，触控友好）|
| 卡片（DramaCard） | `16px`（图文卡），纯图卡 `0` + 外层 gap |
| 输入框 / Select | `12px 14px`（高 ≥ 44px）|
| 面板 / Sheet | `24px` |
| 导航项 | `10px 16px` |
| 列表行 | `12px 16px` |
| 段落间距 | 同层级段落间 `margin-top: 1em`（即 16px @16px）|

### 4.4 栅格与垂直韵律（Vertical Rhythm）
- 页面主内容最大宽度 `1200px`（居中，`--container`），首页 Hero 可满宽。
- Section 之间垂直间距 `space-2xl`（64px），首页 Hero 区域 `space-3xl`（96px）。
- 卡片网格 gap：`space-lg`（24px）桌面 / `space-md`（16px）移动。
- 任何"看起来挤"的页面，先加 section 间距，再加卡片内边距，**最后**才考虑减内容。

## 五、圆角 / 阴影 / 描边 / 动效

### 5.1 圆角（Radius）
```
--radius-sm 8px    标签 / 徽章 / 小控件
--radius-md 12px   按钮 / 输入框
--radius-lg 16px   卡片 / 面板
--radius-xl 20px   大卡 / Sheet / Hero 块
--radius-full 999px 头像 / 胶囊按钮 / 进度条
```

### 5.2 阴影（分层、低透明度、柔和）—— "高端"靠它出层次
```
--shadow-1 0 1px 2px oklch(0 0 0 / 0.06), 0 1px 3px oklch(0 0 0 / 0.10)
--shadow-2 0 4px 12px oklch(0 0 0 / 0.10), 0 2px 4px oklch(0 0 0 / 0.06)
--shadow-3 0 12px 32px oklch(0 0 0 / 0.16), 0 4px 8px oklch(0 0 0 / 0.08)
--shadow-brand 0 8px 24px oklch(0.68 0.19 18 / 0.35)  /* 强调色辉光，仅 CTA hover */
```
> 深色主题下阴影需更克制（底色已深），主要靠 `surface` 层阶 + `border` 拉开层次，阴影作点缀。

### 5.3 描边（Border）
统一 `1px solid var(--color-border)`；悬浮/聚焦用 `border-strong` 或 `brand-soft`。

### 5.4 动效（Motion）
```
--ease-out  cubic-bezier(0.22, 1, 0.36, 1)
--dur-fast  150ms
--dur-base  220ms
--dur-slow  320ms
```
- 悬浮：translateY(-2px) + shadow-2 → shadow-3，`dur-base`。
- 出现（fade+rise）：opacity 0→1, translateY(8px)→0，`dur-base`。
- **强制**：所有动效包在 `@media (prefers-reduced-motion: reduce)` 下关闭位移与淡入，仅保留必要状态切换。

## 六、组件库（基于 shadcn/ui，间距已内建）

> shadcn 组件默认偏紧凑，需按本系统覆写 tokens。以下为 DramaVN 核心组件及**强制间距**。

| 组件 | 关键规范 |
|---|---|
| **Button** | 高 ≥44px；primary 用 `brand`，hover `brand-strong`+`shadow-brand`；大写标签 `tracking +0.08em`；禁用态降透明度 + `not-allowed` |
| **DramaCard**（剧集卡） | 图文卡 padding 16px；封面 2:3 或 16:9；标题 `text-h4`+`line-clamp-2`；底部元信息 `text-caption`+`text-muted`；hover 封面轻微放大(scale 1.03)+`shadow-3` |
| **NavBar** | 吸顶 + `backdrop-blur` + 半透明 `bg`；项 `padding 10px 16px`；右侧双语切换 + 余额/头像；移动端折叠为抽屉 |
| **Hero** | 满宽背景图/视频 + 暗化渐变；主标题 `text-display`；CTA 按钮间距 `space-md`；上下留白 `space-3xl` |
| **EpisodeList** | 行 `padding 12px 16px`；集数徽章 `radius-full`；锁定集显示锁图标 + 解锁价；hover 行 `surface-2` |
| **UnlockSheet**（解锁付费弹层） | 底部抽屉/居中面板；内边距 24px；价格大字 `text-h2`；确认按钮全宽；`focus-trap` + ESC 关闭 |
| **Player**（播放器） | 控件半透明条；进度条 `radius-full`；标题 `text-h4`；错误/加载/空状态三态齐备 |
| **Badge / VIP** | 用 `gold` 仅限会员；`radius-full` + `tracking +0.06em` |
| **Input / Select** | 高 ≥44px；`padding 12px 14px`；focus 显式 `ring`（见 §七）|
| **Toast** | 右下角；`radius-md` + `shadow-2`；自动消失 4s；支持 aria-live |

## 七、交互逻辑规范（Interaction）

### 7.1 五态齐全（每个可交互元素必须有）
`default / hover / active(pressed) / focus-visible / disabled`。**禁止**只做 hover 不做 focus——键盘用户会"看不见自己在哪"。

### 7.2 焦点环（Focus Ring）— 强制可见
```css
:focus-visible {
  outline: 2px solid var(--color-brand);
  outline-offset: 2px;
  border-radius: inherit;
}
```
所有可聚焦元素（`a / button / input / [tabindex]`）必须呈现此环。这是"国际范"与无障碍的底线。

### 7.3 导航与双语切换
- 右上角语言切换：`VI | 中文`，点击切换并写入 `locale`（vi/zh），URL 同步 `/zh/...`（见 01 US-3）。
- 切换时**不跳变布局**：两种语言共用同一字阶，zh 用 PingFang/Noto 回退，vi 用 Jakarta/Inter。
- 记忆偏好：localStorage + cookie，下次访问默认。

### 7.4 解锁付费流（状态机）
```
[locked] --点击解锁--> [confirm sheet] --确认支付--> [processing] --webhook PAID--> [playing]
                                          └--取消--> [locked]
[processing] --失败/超时--> [error toast] --重试--> [confirm sheet]
```
- 每个状态都要有 UI：locked 显示锁+价；processing 显示 spinner（禁用重复点击）；playing 显示播放器；error 有 toast + 重试。
- 重复点击防护：processing 期间按钮 `disabled` + `aria-busy`。

### 7.5 无障碍（A11y）
- 全站键盘可达，模态 `focus-trap` + ESC 关闭 + 背景 `inert`。
- 图标按钮带 `aria-label`；装饰图 `alt` 或 `aria-hidden`。
- 颜色不作为唯一信息载体（锁/价/状态同时用图标+文字）。
- 对比度达标（见 §2）。

### 7.6 动效克制
- 列表/卡片入场用统一样式（fade+rise），不要每种组件各写一套。
- 任何 >300ms 的动画需谨慎；加载等待用 skeleton 而非转圈占位整屏。

## 九、双语与越南语变音专项

1. **变音不被裁切**：`line-height` 永不低于 1.5（标题也要留 descender 空间）；`font-feature-settings` 开 `calt/kern`；字体只用 Jakarta/Inter/PingFang/Noto（均已验证越南语）。
2. **中文回退**：zh 文案自动落到 PingFang SC / Noto Sans SC，字距规则同样适用（中文不需负字距，正文 `letter-spacing:0`）。
3. **同字阶不同字重**：越南语用 Jakarta 的中等字重即可显精致；中文用 PingFang 常规字重，避免过粗发虚。
4. **数字/货币**：越南盾 `₫` 用等宽数字 `font-variant-numeric: tabular-nums`，价格对齐更"国际范"。

## 十、落地方式（Tailwind v4 + shadcn）

### 10.1 `globals.css`（令牌 + reset 核心）
```css
@import "tailwindcss";

@theme {
  /* 颜色（深色为默认，见 §2.1）*/
  --color-bg: oklch(0.16 0.005 250);
  --color-surface-1: oklch(0.20 0.006 250);
  --color-surface-2: oklch(0.25 0.007 250);
  --color-surface-3: oklch(0.31 0.008 250);
  --color-text: oklch(0.97 0.003 250);
  --color-text-muted: oklch(0.72 0.006 250);
  --color-brand: oklch(0.68 0.19 18);
  --color-brand-strong: oklch(0.62 0.20 18);
  --color-gold: oklch(0.82 0.12 85);
  /* 间距语义令牌（§4.2）*/
  --spacing-xs: 0.25rem; --spacing-sm: 0.5rem; --spacing-md: 1rem;
  --spacing-lg: 1.5rem; --spacing-xl: 2.5rem; --spacing-2xl: 4rem; --spacing-3xl: 6rem;
  /* 圆角 / 阴影 / 动效（§5）*/
  --radius-lg: 1rem; --radius-xl: 1.25rem;
  --shadow-2: 0 4px 12px oklch(0 0 0 / 0.10);
  --ease-out: cubic-bezier(0.22, 1, 0.36, 1);
  --dur-base: 220ms;
}

:root {
  text-rendering: optimizeLegibility;
  -webkit-font-smoothing: antialiased;
  -moz-osx-font-smoothing: grayscale;
  font-feature-settings: "kern" 1, "liga" 1, "calt" 1;
}

body {
  font-family: "Plus Jakarta Sans", "Inter", "PingFang SC", "Noto Sans SC", system-ui, sans-serif;
  line-height: 1.65;            /* 正文行高底线 */
  color: var(--color-text);
  background: var(--color-bg);
}

/* 大写标签强制字距（§3.3 铁律）*/
.uppercase { letter-spacing: 0.1em; }

:focus-visible {
  outline: 2px solid var(--color-brand);
  outline-offset: 2px;
}

@media (prefers-reduced-motion: reduce) {
  *, *::before, *::after { animation: none !important; transition: none !important; }
}
```

### 10.2 用法示例
```tsx
// 卡片标题：字号 + 行高 + 字距 全来自令牌
<h3 className="text-h4 font-semibold tracking-tight leading-snug line-clamp-2">
  {drama.title}
</h3>
<p className="text-body-sm text-muted leading-relaxed mt-2">
  {drama.description}
</p>
```

## 十一、验收清单（Do / Don't）— 开发自测用

**Do ✅**
- [ ] 正文 `line-height ≥ 1.65`，标题按 §3.4 取值。
- [ ] 任何 `uppercase` 元素 `letter-spacing ≥ 0.08em`。
- [ ] 卡片内边距 ≥ 16px，按钮高 ≥ 44px，控件间距 ≥ 16px。
- [ ] Section 之间 ≥ 64px 垂直留白。
- [ ] 焦点环对所有可交互元素可见。
- [ ] 越南语变音完整显示、无裁切。
- [ ] 颜色全部来自令牌，无散落 hex。

**Don't ❌**
- [ ] 不要把正文行高写成 1.2 / 1.3。
- [ ] 不要给正文加负字距。
- [ ] 不要用 2px / 6px / 10px 这类"将将够"的间隙。
- [ ] 不要只做 hover 不做 focus-visible。
- [ ] 不要在组件里写魔法数字颜色/间距（用令牌）。
- [ ] 不要靠双倍行高撑段落，用 `margin`。
