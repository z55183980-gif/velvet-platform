## 三、观众端实录

### V3-01（P0 回归）切换语言 / navigate 后登录态丢失
- **步骤**：登录 → 切换语言 → 访问任意子页面
- **期望**：登录态保留
- **实际**：详情页顶部 nav 出现"登录"按钮，余额显示"—"，HLS 播放器锁屏提示"Đăng nhập để xem"
- **截图**：`V-18-detail-zh.png`、`V-20-home-reload-zh.png`、`V-19-me-zh.png`
- **影响**：**P0 严重**，用户付费后看不到已解锁的剧集，会要求重复付费
- **推测根因**：v1 报告 P1-8 的 cookie/auth 双轨问题未真正修复——前端 `auth-context` 早期 mount 时 session 检查时序问题
- **建议修复**：让所有 fetch 都强制 `credentials: include`；或在 AuthProvider 加 `mounted` flag

### V3-02（P0）`/zh` 路由 404
- **步骤**：浏览器输入 `http://localhost:3000/zh`
- **期望**：返回中文首页（文档 [01 §3.5] 明确说"URL 路由前缀 `/zh/...`"）
- **实际**：返回 Next.js 默认 404 页面（"This page could not be found"）
- **截图**：`V-15-404.png`
- **影响**：中文 SEO 与分享链路全断
- **推测根因**：i18n 实际是**客户端 context 切换**而非 URL 路由分层；docs 描述与实现不一致
- **建议修复**：要么补全 `/zh/[...path]` 路由层，要么更新 docs 删除该承诺

### V3-05（P1）解锁抽屉标题歧义
- **步骤**：点付费集 4 → 弹出抽屉
- **期望**：标题 "Mở khóa tập 4"（解锁第 4 集）
- **实际**：标题为 "Danh sách tập 4"（剧集列表 第 4 集）—— 上下文错乱
- **截图**：`V-04-unlock-sheet.png`
- **影响**：用户以为"剧集列表"，不明确知道是"解锁"
- **建议修复**：`unlock-sheet.tsx` 第 144 行：`{t("detail.episodeList")} {ep.episodeNumber}` 改为 `{t("unlock.episodeNumber", {n: ep.episodeNumber})}`

### V3-06（P1 回归）已解锁集仍显示价格
- **步骤**：解锁集 4（10 积分）→ 看集列表
- **期望**：集 4 显示"已解锁"
- **实际**：集 4 标签变成"Đã mở khóa" ✅；但集 5（也是付费且未解锁）显示"10 积分"，未联动 enabled
- **截图**：`V-08-unlocked.png`
- **影响**：用户可能误以为集 5 仍需付费
- **建议修复**：`episode-list.tsx` 判断 unlocked 时同时考虑 `isFree || unlocked`，已部分修但应全面覆盖

### V3-14（P1）播放器覆盖整个视口，esc 无效
- **步骤**：点击集 1 → 播放视频
- **期望**：视频在 hero 区播放，下方仍可见剧集列表
- **实际**：视频 fixed/sticky 充满整个视口，按 esc 无反应，用户必须滚动才能看下方
- **截图**：`V-03-ep1-play-3s.png`
- **影响**：用户体验断层，怀疑是否进入了全屏
- **建议修复**：播放器应使用 `aspect-video` + `position: relative` 而非 fixed 全屏

### V3-15（P1）个人中心 `/me` 中文模式空白
- **步骤**：登录态访问 `/me`，切换到中文
- **期望**：显示钱包/订单/收藏/历史 tab
- **实际**：页面完全空白（无文案、无骨架屏、无错误提示）
- **截图**：`V-19-me-zh.png`
- **影响**：中文用户不知道页面加载出错
- **建议修复**：`me/page.tsx` 检查 zh locale 文案是否完整（很可能 switch case 漏了 zh）

### V3-16/17（P2）顶部搜索栏 / 全部分类页缺失
- **步骤**：从首页试图搜剧 / 切分类
- **期望**：顶部搜索框；侧拉或全部分类页
- **实际**：搜索只能通过 URL `?q=`；分类只有首页顶上一个 chip（ngon_tinh）
- **影响**：核心发现功能缺少 UI 入口
- **建议修复**：增加 search-bar component 和全部分类下拉页

### V3-18（P2）404 页面英文
- **步骤**：访问不存在的 URL
- **期望**：i18n 一致的 404 文案
- **实际**：英文 "This page could not be found"（Next.js 默认）
- **截图**：`V-15-404.png`
- **建议修复**：自定义 `app/not-found.tsx` + 引入 t()

### V3-26（P2）VI 模式下出现中文"积分"
- **步骤**：VI 模式下点付费集
- **期望**：抽屉内全越文
- **实际**："10 积分" / "0 积分" / "100 积分" 全部中文残留
- **截图**：`V-04-unlock-sheet.png`
- **影响**：双语混用
- **建议修复**：`i18n.tsx` 补 `card.credits` 的越文翻译（已有但似乎有些调用未用 key）
