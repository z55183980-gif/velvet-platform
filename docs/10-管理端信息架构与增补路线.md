# 10 · 管理端信息架构与增补路线

> 对应侧栏重构（2026-08）。实现以 `apps/admin/components/admin-shell.tsx` 为准。

## 侧栏分组

| 分组 | 菜单 |
|------|------|
| 工作台 | 数据概览、经营报表 |
| 内容 | 剧集管理、内容审核、分类管理 |
| 运营 | 首页轮播、推荐位、消息推送 |
| 用户 | 用户列表、封禁风控 |
| 交易 | 订单中心、退款审核、充值套餐、VIP会员、兑换码 |
| 创作者 | 创作者管理（含 KYC Tab）、提现审核 |
| 财务 | 资金流水、对账结算（含 T+7 Tab） |
| 系统 | 管理员、操作日志、系统配置（含汇率 Tab） |

## 本轮变更

- 整套壳重做：可折叠侧栏、顶栏账号下拉、移动端抽屉
- **新增** `/refunds`（从订单抽出）、`/admins`（从设置抽出）
- **合并后硬删**：`/kyc` → `/creators?tab=kyc`；`/settle` → `/reconcile?tab=settle`；`/rates` → `/settings?tab=rates`
- 批量导入不再挂侧栏，仅剧集管理页内入口 `/content/import`
- 封禁风控菜单：`/users?status=BANNED`

## 已清理的重复 / 不合理独立入口

- `/kyc`、`/settle`、`/rates` 页面文件已删除（能力保留在合并目标页）
- 订单页退款 Tab、设置页管理员区块已删除（迁至独立页）
- 内容排行 `/ranking`、运营优惠 `/ops`：此前已删除

## 明确延后

直播、广告、字幕工作室、DRM/CDN 控制台、工作室多成员、二级分销、评论管理。
