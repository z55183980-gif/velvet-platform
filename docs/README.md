> **更新日期**：2026-07-29

## 一句话定位

面向越南市场的 **纯 Web 短剧平台**：官方可上内容、创作者可上传分成、观众部分免费部分付费；**双语 Day1**；**越南+国内支付接口 Day1 预留**；先把地基打牢，再迭代增强。

---

## 地基原则（冻结，不允许摇摆）

| # | 原则 |
|---|---|
| 1 | **单域名路径分区**：`/` 观众 · `/creator` 创作者 · `/admin` 管理（不做多子域名） |
| 2 | **账本只认 VND**；订单保存实付币种 + 汇率快照（微信/支付宝/Stripe 可审计） |
| 3 | **支付走 PaymentProvider 抽象**；渠道可插拔；Webhook **幂等**；**日对账**骨架必有 |
| 4 | **HLS 短时签名 URL**，禁止永久公开片源链接 |
| 5 | **双语 Day1**（vi 默认 + zh 中文） |
| 6 | **写钱必须事务 + 幂等 + 钱包 version** |
| 7 | **8 周可商业化上线**；前 2 周只打地基，不堆花活 |
| 8 | **官方脚手架自建**，不整仓依赖冷门模板 |

---

## 商业闭环（必须真跑通）

```
观众注册 → 充值 → 解锁付费集 → 播放
创作者认证 → 上传 → 审核 → 上架 → 获得 70% 收益 → 提现
平台抽成 30% + 内容审核 + 提现复核
```

默认分成：`创作者 70% / 平台 30%`（官方自制可记为平台 100%）。

## 必做基础能力（运营离不开）

### A. 双语（Day1）

- UI / 路由 / 短剧标题简介 / SEO / 金额日期时区全部 **vi（越南语）+ zh（中文）**
- 分类用 slug + i18n key（不要只存单语文案）

### B. 支付（接口 Day1，接通分优先级）

| 优先级 | 渠道 | 要求 |
|---|---|---|
| P0 | 支付抽象 + 幂等 Webhook + 日对账骨架 | 必做 |
| P0 | 银行转账（后台人工确认） | 必做兜底 |
| P0 | VietQR 或聚合（PayOS/Casso）**至少 1 条自动收款** | 必做 |
| P1 | Stripe | 接通（注意越南卡支持有限） |
| P1 | 微信 + 支付宝 | 接口+sandbox/生产（视商户资质） |
| P2 | MoMo / ZaloPay **生产** | 接口与 sandbox Day1 预留，生产审核后开 |

用户**手动选**支付方式；IP/语言只影响默认排序，不做强制。

### C. 内容与片源

- 上传（TUS 断点续传）→ FFmpeg → HLS（480p/720p）→ CDN
- 播放必须带短时签名
- 免费前 N 集（默认 3，可配置）

### D. 用户与创作者

- 手机号 OTP 登录（SMS 可先 mock，W2 换真通道）
- 创作者 CCCD + 绑卡（人脸可先人工）
- 钱包 / 订单 / 收藏 / 观看历史（upsert）
- 提现门槛 100,000 ₫，T+7

### E. 平台

- 内容审核、提现审核、Banner、基础看板
- 系统配置表（免费集数、汇率、分成、提现门槛）

### F. 稳定与性能（务实）

- 索引 + 连接池 + Redis 热点缓存 + 每日备份
- 视频走 CDN；应用先单机/双实例，再谈读写分离
- 上线目标：**千级同时在线稳定**；万级是增长期目标
